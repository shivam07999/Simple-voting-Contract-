# Simple Voting Contract

## Project Description
The **Simple Voting Contract** is a basic decentralized voting system built with Solidity.  
It allows participants to vote for predefined candidates on the blockchain, ensuring **fairness, transparency, and immutability** of results.

## Project Vision
To create a **secure, transparent, and trustless voting system** using blockchain, preventing vote manipulation and double voting, while ensuring results are publicly verifiable.

## Key Features
- **Candidate Initialization:** The contract starts with a list of candidates.
- **One Vote Per User:** Each wallet address can only vote once.
- **Vote Tallying:** Anyone can check the vote count of candidates.
- **Winner Calculation:** The contract determines the candidate with the most votes.

## Future Scope
- Add **time-based restrictions** (start & end of election).
- Enable **dynamic candidate registration**.
- Introduce **admin-only privileges** for better control.
